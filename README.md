1. Tujuan repositori
   Menyimpan dan mengurus fail projek serta sejarah perubahan.
2. Kepentingan branch
   Membolehkan perubahan dibuat tanpa mengganggu projek utama.
3. Perbezaan commit dan pull request
   Commit:Menyimpan perubahan kod.
   Pull Request:Memohon untuk menggabungkan perubahan ke branch lain.
4. Mengapa guna GitHub?
   Untuk menyimpan kod, bekerjasama dengan pasukan, dan mengurus projek dengan mudah.
